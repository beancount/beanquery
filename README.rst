beanquery: Customizable lightweight SQL query tool
==================================================

beanquery is a customizable and extensible lightweight SQL query tool
that works on tabular data, including `Beancount`__ ledger data.

__ https://beancount.github.io/

Documentation
-------------

- Official documentation at `GitHub Pages <https://beancount.github.io/docs/beancount_query_language/>`_

- Community-maintained `Interactive beanquery manual <https://github.com/Ev2geny/beanquery-interactive-manual>`_
